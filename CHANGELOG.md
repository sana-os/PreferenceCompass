# Changelog

## Public release 1.0.0

- Seven language/script editions, each with 100 aligned questions and four choices.
- Explicit uncertainty, context, non-applicability and refusal states.
- Original-language free text; browser persistence; review before export.
- Self-contained Markdown/JSON, schema and protocol 1.1.0; questionnaire 2.0.0.
- Initial observations have null beliefs; optional evidence-counting model documented.
- Localized HTML and Markdown, public schema/protocol, crawler and AI documentation.
- Static Cloudflare Pages build with no runtime dependencies.

This supersedes the earlier English prototype. Local legacy responses are sanitized on migration; unknown input languages remain marked undetermined. Translations have not been independently reviewed.
